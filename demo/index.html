RESPUESTA SIMULADA

Reglas de control

SoD separa operación de aprobación y administración de auditoría.

Idempotencia conserva un único ID y evento cuando el actor y el contenido normalizado coinciden.

SHA-256 vincula cada evidencia con la anterior. No equivale a un registro WORM.

Cada hash se calcula con Web Crypto sobre JSON UTF-8 con hash: "" y previousHash incluido. La copia alterada no modifica la evidencia original.

Verificá la cadena para recalcular sus hashes.

LO QUE EXPLORÁS

El comportamiento del MVP

  • Validación de solicitudes y roles; errores 400 para entradas inválidas.
  • Conflictos SoD registrados como Rejected con respuesta 202.
  • Misma clave, actor y contenido normalizado: 202, sin duplicar evidencia.
  • Misma clave con distinto contenido o actor: 409, sin mutar el registro.
  • SHA-256 real, verificación de enlaces y secuencias.

FRONTERAS EXPLÍCITAS

Una demo, no un IAM

  • No consume la API .NET ni prueba su autenticación.
  • El actor está fijo en demo-technical-principal; no representa una identidad humana autenticada.
  • No crea, modifica, aprueba ni deshabilita cuentas.
  • No verifica versiones de cuentas ni conecta Active Directory.
  • Estado en memoria: máximo 100 solicitudes únicas; sin persistencia ni concurrencia distribuida.
